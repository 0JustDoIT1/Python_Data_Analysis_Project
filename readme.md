# 🌡️ 기상요인이 범죄 발생에 미치는 영향 분석

> **Does Hot Weather Really Increase Crime?**  
> 한국 월별 시계열 데이터를 활용한 기상·범죄 유형별 관계 분석  
> `2014.01 ~ 2024.12` · `132개월` · `생산가능인구 10만명당 범죄율`

---

## 📌 프로젝트 개요

매년 심화되는 폭염은 불쾌지수와 스트레스를 증가시키며, 여름철 범죄 증가는 이미 사회적으로 인식된 현상입니다.  
그러나 **한국 데이터를 기반으로 시계열로 체계적으로 분석한 연구는 부족**합니다.

이 프로젝트는 기온·습도·열대야·강수량 등 **복합 기상 변수**와 폭력·흉악·재산 **3가지 범죄 유형** 간의 관계를  
다양한 통계 분석 기법으로 검증하고, **데이터 기반 정책 방향**을 제시합니다.

---

기상 요인은 범죄 발생률 증가로 이어지는가?

## 📊 분석 방법론

```
EDA → 정상성 검정 → STL 분해 → OLS 회귀 → CCF → Granger 인과검정 → SHAP → 예측
```

| Step | 기법 | 목적 |
|------|------|------|
| 1 | **ITS 중단시계열** | 코로나 구조 변화 확인 |
| 2 | **ADF / KPSS** | 정상성 검정 |
| 3 | **STL 분해** | 계절성 제거, CCF 입력값 준비 |
| 4 | **Breusch-Pagan + White** | 이분산성 검정 |
| 5 | **OLS 회귀 (HC3)** | 기상변수 순수 효과 추정 |
| 6 | **Piecewise Regression** | 임계점(불쾌지수 68) 탐색 |
| 7 | **t검정 (열대야 그룹)** | 열대야 유무별 범죄율 차이 |
| 8 | **분위수 회귀** | 분포 극단에서의 기상 효과 |
| 9 | **CCF** | 기상-범죄 시차 상관 분석 |
| 10 | **Granger 인과검정** | 기상변수의 시간적 선행성 |
| 11 | **Random Forest + SHAP** | 변수 중요도 종합 비교 |
| 12 | **SARIMAX + Prophet** | 범죄율 예측 및 백테스팅 |

## 📂 데이터 전처리

```
데이터 통합 → 결측치 처리 → 범죄율 표준화 → 파생변수 생성
```

- **기상·범죄·인구·실업률** 데이터를 월별 기준으로 통합
- 열대야 0값은 측정 오류가 아닌 실제 미발생으로 원값 유지
- 범죄율 = 발생건수 / 생산가능인구 × 100,000
- 파생변수: 불쾌지수 (기온·습도 복합), 코로나 더미 (2020.03~2022.04)

## 🔑 핵심 발견

### 1️⃣ 불쾌지수 — 가장 강력한 기상 예측변수
모든 범죄 유형에서 일관된 양(+)의 효과. Granger 검정에서 Lag 1~3 유의.  
OLS 기준 폭력·흉악범죄 R² ≈ 0.67 수준의 설명력.

### 2️⃣ 범죄 유형별 기상 민감도 차이 존재
```
흉악범죄 > 폭력범죄 > 재산범죄
```
- **흉악범죄**: 열대야 있을 경우 범죄율 약 **22% 상승** (야간 고온 → 수면부족 → 충동조절 저하)
- **폭력범죄**: 불쾌지수 양의 효과, 강수량 증가 시 외출 억제로 감소
- **재산범죄**: 기상요인보다 **사회경제 구조 요인**이 주도 (실업률 SHAP 1위)

### 3️⃣ SHAP 변수 중요도 (Random Forest 기반)

| 범죄유형 | 1위 | 2위 | 3위 |
|----------|-----|-----|-----|
| 폭력범죄 | 실업률 (3.60) | 불쾌지수 (3.22) | 코로나더미 (1.46) |
| 흉악범죄 | **불쾌지수 (1.09)** | 실업률 (0.42) | 일조시간 (0.19) |
| 재산범죄 | 실업률 (7.57) | 불쾌지수 (3.91) | 강수량 (1.22) |

### 4️⃣ 예측 결과 (SARIMAX, 2025~2026)

| 범죄유형 | 2024 실제 | 2025 예측 | 2026 예측 | 방향 |
|----------|-----------|-----------|-----------|------|
| 폭력범죄 | 약 40 | 40.09 | 38.90 | ↘ 완만한 하락 |
| 흉악범죄 | 약 9 | 8.66 | 8.29 | ↘ 소폭 감소 |
| 재산범죄 | 약 185 | 194.93 | 214.16 | ↗ **강한 상승** |

## ✅ 가설 검증 요약

| 가설 | 내용 | 결과 |
|------|------|------|
| H1 | 기상변수↑ → 범죄↑ | 🟡 부분 지지 (폭력·흉악 유의, 재산 미유의) |
| H2 | 1~3개월 시차 효과 존재 | 🟡 부분 지지 (불쾌지수 Granger 유의) |
| H3 | 폭력범죄가 기상에 가장 민감 | 🔴 기각 (흉악 > 폭력 > 재산) |
| H4 | 계절성 제거 후 순수 기상효과 | 🟡 부분 지지 (불쾌지수→흉악 Lag 2, p=0.040) |
| H5 | 교란변수 통제 후에도 기상효과 유지 | 🟢 지지 (1차 차분 후 Granger 전 범죄 유의) |
| H6 | 임계점 초과 시 범죄 급증 | 🟡 부분 지지 (재산범죄, 불쾌지수 68 초과) |
| H7 | 폭염 시나리오 기반 예측 가능 | 🟡 부분 지지 (폭력·재산 MAPE <8%, 흉악 불량) |

## 💡 정책 제언

### 🚨 불쾌지수 기반 범죄위험 경보 시스템
- 임계점 **68 = 주의** / **75 = 경계**
- 기상청 예보 자동 연계 → 경찰청 사전 대응 체계 구축

### 🌙 열대야 집중 야간 순찰 강화
- 열대야 발생 시 야간(22시~익일 4시) 순찰 밀도 강화
- 연속 3일 이상 시 비상 근무 체계 가동

### ☀️ 폭염 취약계층 복합 지원
- 폭염기 무더위 쉼터 확대
- 폭염 + 경기 침체 중복 시 집중 대응

## ⚠️ 한계점 및 향후 연구

### 데이터 한계
- 전국 단위 월별 집계 → 지역별·일별 분석 불가
- 신고되지 않은 범죄(암수범죄) 미반영

### 방법론 한계
- Granger 인과는 시간적 선행성이며 물리적 인과 아님
- 공격성·스트레스 등 실질적 매개변수 분석 불가

### 향후 연구 방향
- 시도별 패널 데이터로 지역별 기상·범죄 민감도 비교
- 일별 데이터 확보 → 즉각 효과 및 1~7일 시차 검정
- 공격성·스트레스 지수 등 매개변수 확보 → 인과 경로 분석
